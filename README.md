# Haxcel

Лабораторна робота №1, варіант 3. 
Виконувала студентка групи К-28 Харченко Поліна.

## Завдання

У клітинках таблиці записуються арифметичні вирази. Програма перевіряє синтаксис виразу, обчислює його значення і показує його в таблиці.

Варіант 3, набір операцій:
- `+`, `-`, `*`, `/` (бінарні);
- `mod`, `div`;
- унарні `+` і `-`;
- `max(x, y)`, `min(x, y)`.

У виразах можна використовувати цілі числа довільної довжини, адреси клітинок (`A1`, `B12`) та круглі дужки.

## Можливості

- введення і редагування виразів у клітинках;
- два режими показу: **значення** і **вираз**;
- додавання та видалення рядків і стовпчиків (з підтвердженням для непорожніх);
- збереження таблиці у файл JSON і читання з файлу;
- повідомлення про помилки: синтаксична (з позицією символу), ділення на нуль, циклічне посилання, неіснуюча клітинка;
- довідка та інформація про програму;
- головне меню і кнопки, що його дублюють.

## Як працює обчислення виразу

1. Лексер і парсер ANTLR (`Calculator.Parse`) будують дерево розбору. Якщо у виразі помилка, кидається `ExpressionException` з позицією символу.
2. `Visitor` обходить дерево і обчислює значення (`BigInteger`). Ділення на нуль дає `CalculationException`.
3. `TableData` обчислює клітинки, на які є посилання, і знаходить цикли.

Правила для ділення (числа цілі):
- `a / b` відкидає дробову частину: `-7 / 2 = -3`;
- `a div b` округлює вниз: `-7 div 2 = -4`;
- `a mod b` повертає остачу зі знаком дільника: `-7 mod 2 = 1`.

## Запуск

Програма працює на Windows і на macOS. Потрібні .NET 10 SDK і workload MAUI.

Тести:

```
dotnet test Haxcel.Tests
```

Windows:

```
dotnet run --project HaxcelApp -f net10.0-windows10.0.19041.0
```

macOS:

```
dotnet run --project HaxcelApp -f net10.0-maccatalyst
```

Проєкт сам вибирає цільову платформу: на Windows збирається Windows-версія, на macOS збирається Mac Catalyst.

Під час першої збірки Antlr4BuildTasks завантажує Java і генерує лексер та парсер з файлу `LabCalculator.g4`, тому потрібен інтернет.

## Як користуватись

1. Клікніть на клітинку, введіть вираз і натисніть Enter або перейдіть в іншу клітинку.
2. Кнопка «Режим» перемикає показ значень і виразів.
3. Кнопка «Порахувати» перераховує всю таблицю.
4. Кнопка «Зберегти» записує таблицю у файл `table.json`: у Windows це папка «Документи», у macOS папка Documents у контейнері програми.
5. Кнопка «Прочитати» відкриває вікно вибору файлу. Приклади лежать у папці `TestData`.
